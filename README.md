The Bureau

The Bureau is a cooperative third-person extraction shooter about Agents working for the Bureau of Research and Neutralization - BRN, a government organization tasked with investigating, researching, and neutralizing phenomena.

Players deploy into unstable environments, complete unpredictable assignments, confront hostile entities and anomalies, and attempt to return before their extraction window closes.

The Bureau treats the impossible like paperwork.

Investigate it.
Classify it.
Neutralize it.
File the report.

Preferably return alive.

This repository contains the playable demo / vertical slice currently in development.
